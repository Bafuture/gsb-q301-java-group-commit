## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们每次写入都单独落盘，磁盘 IO 次数太多，但每条都等太久又会拖慢响应。请从零实现一个组提交（group commit）组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 多个并发的写入请求被攒成一组，一次性落盘后统一返回；2) 支持按批量大小或等待时间触发提交，先到者生效；3) 落盘失败时本组全部请求都要返回失败，不得出现部分成功部分失败，需有测试证明；4) 支持同步与异步两种等待方式：同步等待本组落盘结果，异步通过回调通知；5) 支持顺序保证：同一连接内提交的多条写入落盘后顺序不变；6) 支持并发正确性：高并发写入下不得丢失请求，也不得重复落盘同一请求；7) 给出批量大小对平均提交延迟与 IO 次数的影响数据；8) 测试覆盖组提交触发、失败整组回滚、同步异步等待、顺序保持、并发不丢不重与数据对比；`mvn -q verify` 一条命令跑通。

## 提交要求

1. 在本仓库中完成提示词要求的全部内容。
2. `./mvnw -q verify` 必须通过。
3. 完成后在所属分支（A 或 B）上提交，产物快照的父提交必须是初始环境快照。
